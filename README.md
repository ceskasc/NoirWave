## ✨ The Vision

**NoirWave** is a concept for an elite, immersive web application designed for audiophiles. Built with state-of-the-art web technologies, it transcends the typical music streaming interface. Through heavy use of **glassmorphism, cinematic typography, atmospheric film grain, and hardware-accelerated animations**, the application feels less like a website and more like a high-end operating system from the year 2077.

## 🚀 Key Features

*   **Fluid Audio Engine:** A custom-built player using actual browser `<audio>` APIs underneath a breathtaking UI.
*   **Absolute Scrubbing Precision:** Invisible native `<input type="range">` elements are overlaid on gorgeous gradients, ensuring UI manipulation is flawless and never loses mouse tracking.
*   **Dynamic Visuals:** Every interaction, from opening the Notifications panel to hovering over an album, triggers buttery-smooth `framer-motion` layout animations.
*   **Vast Scale:** Includes mock generation for over 10 Artists, 15 Albums, 30 Tracks, and curated Playlists spanning Cinematic, Lofi, Cyberpunk, and Jazz.
*   **Premium Detailing:** Optical alignment fixes, customized scrollbars, neon glows, and a subtle `.02` opacity cinematic film grain.

## 💻 Getting Started (Local Development)

To run NoirWave locally and experience the aesthetic firsthand:

```bash
# Clone the repository
git clone https://github.com/ceskasc/NoirWave.git

# Navigate into the project directory
cd NoirWave

# Install dependencies (Force legacy peer deps if needed)
npm install --legacy-peer-deps

# Start the Turbopack development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. Prepare your headphones.
